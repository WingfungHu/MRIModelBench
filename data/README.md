# Dataset

This project uses the [Brain Tumor MRI Dataset](https://www.kaggle.com/datasets/masoudnickparvar/brain-tumor-mri-dataset) by Masoud Nickparvar.

The dataset is not included in this repository in order to prevent any potential incidents with licensing. 

Please download it from the original source and place the `Training/` and `Testing/` directories inside this folder.

See the project dataset card for information about the dataset's sources and licensing.
